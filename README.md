# تطبيق إدارة مراكز تحفيظ القرآن الكريم

نظام شامل لإدارة مراكز وحلقات تحفيظ القرآن الكريم يعمل على Android و iOS.

## المميزات

### أنواع الحسابات
1. **مسؤول النظام** - جميع الصلاحيات
2. **مسؤول المركز** - إدارة مركز واحد
3. **المعلم** - إدارة الحلقة والتقارير
4. **مسؤول التواصل** - مراجعة التقارير والإعلانات
5. **ولي الأمر** - متابعة الأبناء

### الميزات الرئيسية
- ✅ إدارة الحلقات (إضافة/تعديل/حذف)
- ✅ إدارة الطلاب (فردي + استيراد Excel)
- ✅ التقارير اليومية مع تعدد التسميعات
- ✅ الدورات التدريبية والشهادات
- ✅ الأنشطة مع موافقة أولياء الأمور
- ✅ الرسوم والاشتراكات
- ✅ العطل والإجازات
- ✅ الإعلانات
- ✅ العمل أونلاين وأوفلاين
- ✅ المزامنة التلقائية
- ✅ الإشعارات الفورية

## التثبيت والتشغيل

### متطلبات النظام
- Flutter 3.0+
- Node.js 18+
- PostgreSQL 14+

### تشغيل التطبيق

```bash
# تثبيت حزم Flutter
cd quran_center_app
flutter pub get

# توليد كود قاعدة البيانات المحلية
flutter pub run build_runner build

# تشغيل التطبيق
flutter run
```

### تشغيل الخادم

```bash
# تثبيت الحزم
cd backend
npm install

# إعداد قاعدة البيانات
cp .env.example .env
# تعديل .env بإعدادات قاعدة البيانات

npx prisma generate
npx prisma migrate dev

# تشغيل الخادم
npm run dev
```

### بناء APK

```bash
flutter build apk --release
```

### بناء iOS

```bash
flutter build ios --release
```

## التقنيات المستخدمة
